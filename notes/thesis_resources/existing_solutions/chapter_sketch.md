# Existing solutions analysis

Conducting initial market analysis has led us
to several existing solutions, that cover parts of
our planned application scope. In this chapter, we plan
to cover 5 example programs and libraries, that allow 
users to visualize CBCT scan images and segmentation masks.
This analysis is meant to show the positives of each solution,
helping us in replicating them in our application, 
and highlight possible negatives we should avoid.
Information about each tool has been sourced from it's
corresponding website, all of which can be found in the
bibliography. Other figures, for instance - images, will contain
their origin shown beside them.

## Existing solutions analysis criteria

The main criteria we set for evaluating other solutions
are:

#### 1. User experience

Concerning user experience, we decided to
narrow our scope to features our potential user base
would find most important:

- Not requiring specialist knowledge in order to deploy
the application
- Minimal effort required to upload and view scans
- A streamlined and simple user interface

Each tool's user interface covered in this chapter is evaluated 
with these 3 criteria in mind, allowing us to spot design patterns
we should follow or avoid.

#### 2. Image segmentation

Some solutions allow only for viewing uploaded images
or pre-generated segmentation masks, shifting the 
segmentation workload to the user.

#### 3. Support for DICOM and NIfTI file formats

Most tools on the market work only with files in the
DICOM format with no inbuilt support for NIfTI files.

#### 4. Licensing

Existing tools may provide many of the features we strive
to implement, but require a subscription or a one time purchase
with a strict license.

#### 5. The ability to easily modify the software.

The possibility of extending the provided 
functionality, in order to allow the community at large 
to add features not found in the basic version of the tool.
